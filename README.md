## 작성 방식

각 설계 문서는 아래 흐름을 따릅니다. (일반적인 시스템 설계 인터뷰 프레임워크)

1. **요구사항 정의** — 기능적/비기능적 요구사항을 먼저 좁힌다
2. **규모 추정** — QPS, 저장 용량, 대역폭을 대략 계산한다
3. **API 설계** — 외부에 노출할 인터페이스를 정의한다
4. **데이터 모델** — 스키마와 저장소 선택
5. **개략적 설계(High-level)** — 핵심 컴포넌트와 데이터 흐름
6. **상세 설계(Deep-dive)** — 병목 지점을 깊게 파고든다
7. **트레이드오프 / 확장** — 선택의 근거와 한계, 개선 방향
