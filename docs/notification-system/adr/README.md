# notification-system 도메인 ADR 인덱스

`notification-system` 안에서만 영향이 끝나는 결정을 여기 둔다. 여러 서비스에 걸친 결정은 시스템 ADR
([`docs/adr/`](../../adr/README.md))로.

> 기준: "이 결정을 바꾸려면 다른 서비스 코드도 건드려야 하나?" → No면 여기, Yes면 시스템 ADR.

| 번호 | 제목 | 상태 | 날짜 |
|---|---|---|---|
| _아직 없음_ | | | |

> 첫 도메인 ADR을 추가할 때 시스템 ADR(`docs/adr/0001-...`)을 복사해 `0001-...md`로 시작하고 이 표를 갱신한다.
